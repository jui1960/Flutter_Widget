# My Flutter Widget Learning Journey 🚀

This repository is a personal collection of various Flutter widgets and UI components that I have practiced and built while learning Flutter development.

---

## 🎯 Purpose
* To learn and understand basic to advanced Flutter widgets.
* To practice widget properties and UI customization.
* To maintain a clean and organized code structure for future reference.

---

## 📚 Widgets Practiced
* **Layouts:** `Row`, `Column`, `Stack`, `Center`, `Padding`, `SizedBox`.
* **Basic UI:** `Text`, `Container`, `Icon`, `Image`, `Card`.
* **Scrollables:** `ListView`, `GridView`, `SingleChildScrollView`.
* **Buttons & Inputs:** `ElevatedButton`, `TextButton`, `TextField`.
* **Structure:** `Scaffold`, `AppBar`, `Drawer`, `BottomNavigationBar`.
